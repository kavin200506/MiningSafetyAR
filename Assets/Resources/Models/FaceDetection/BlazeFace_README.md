## BlazeFace in Unity 6 with Inference Engine
BlazePose is a fast, light-weight pose detector from Google Research that can be used in Unity using Inference Engine. Pretrained models are available as part of Google's [MediaPipe](https://ai.google.dev/edge/mediapipe/solutions/vision/face_detector) framework.

## How to Use
Example source code to run this model can be found at: [[Source Code](https://github.com/Unity-Technologies/inference-engine-samples/tree/main/BlazeDetectionSample/Pose)

## Inference Engine
Inference Engine is a neural network inference library for Unity. Find out more [here](https://docs.unity3d.com/Packages/com.unity.ai.inference@latest).
